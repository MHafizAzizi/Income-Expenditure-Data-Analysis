## Start of Every Session

Read `context.md` before doing anything else — even for "quick" tasks.
It is the single source of truth for what this project is, what was
decided and why, and what is pending. Do not ask the user to re-explain
the project. Do not rely on git log alone.

## End of Every Session

Update `context.md` before closing:
1. REPLACE the Last Session section with a dated summary of this session.
2. Update Pending Tasks — DELETE completed items entirely; add new ones.
3. Leave What Was Decided intact unless a decision was reversed — then
   rewrite that line to the current state, with the why and the date.
Do not skip this step.
